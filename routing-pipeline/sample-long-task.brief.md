【背景】工业控制 AI 团队在 AMD/Mac 混合算力环境下，正评估将开源 Agent Linger 与现有 DSH 架构融合，以验证云地混编协同方案。

【目标】设计一套可落地的“本地优先”分层任务路由方案：明确本地模型（Workbuddy/Local-Llama）与前处理职责（摘要/整理），界定在线模型核心职责，制定任务分发策略与 Token 节省度量标准。

【关键数据】
1. 硬件约束：无 Docker 环境，Linger 443MB 安装包因网速未部署。
2. 路由限制：仅 Workbuddy 和 Local-Llama 可用，Codex 缺失，豆包需 API 直连。
3. 模型规格：豆包模型 `doubao-seed-2-1-turbo-260628` 含 `reasoning_content` 字段（与 DSH 不兼容）。
4. 业务场景：加热炉 850℃设定值跌至 803℃（持续 8 分钟），伴随炉门异常开启 12 秒及装料量超常 35%。
5. 核心诉求：利用本地模型做廉价预处理，仅将必须推理/决策的任务派发给在线模型以节省 Token。

【建议派发】重度模型（推理/决策）。理由：任务需构建复杂架构的分层路由逻辑、设计跨模型协作流程及制定资源度量指标，涉及系统级推理与策略规划，超出轻量模型的能力范围。
