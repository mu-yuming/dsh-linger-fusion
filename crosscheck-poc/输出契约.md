# 双路 subagent 固定输出契约

两路分析必须使用**完全相同**的 prompt（只换模型路由），并严格按以下四段输出，便于机械对比：

【结论】一句话主因判断
【依据】引用快照中的具体数据点（至少 2 个），标明为何支持该结论
【置信度】高/中/低 + 百分比
【疑点】本结论无法解释的现象，或数据不足之处

## 为什么结构必须固定
裁决逻辑依赖逐段对比。自由格式输出会导致假分歧，无法区分"真实结论差异"与"表达方式差异"。

## 裁决规则（主 Agent 执行）
1. 两路【结论】主因一致且置信度均 ≥ 70% → 采纳，合并双方依据
2. 主因不一致 → 列出分歧点，用 send_message 让各路针对对方疑点复核一轮
3. 复核后仍不一致 → 标记"需人工仲裁"，不自动采纳
4. 全程留审计记录到工作区
